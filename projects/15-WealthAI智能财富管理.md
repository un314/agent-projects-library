# 15 WealthAI 智能财富管理系统

> 持仓监控 + AI 投资顾问 + 实时行情 + 风险预警，意图路由驱动的轻量 Agent。

## 项目定位

个人投资的操作台。把账户、行情、知识、风险放在同一界面，用对话作为统一入口，背后是意图路由到不同工具节点。

## 要解决的问题

- 持仓分散在多个账户，盈亏难以统一查看
- 缺少专业分析能力，看不懂估值与财报
- 投资知识零散，决策缺少依据
- 缺少纪律化的风控提醒，止盈止损常被情绪覆盖

## 核心流程与架构

Agent 采用意图路由结构，`classify_intent` 先判定意图，再走对应节点：

- `handle_portfolio_query`：持仓汇总、盈亏计算、资产配置
- `handle_market_query`：实时报价、历史 K 线、板块表现
- `handle_investment_analysis`：结合 RAG 知识库做基本面与策略分析
- `handle_knowledge_query`：投资知识问答（知识库 + 个人笔记）
- `handle_chitchat`：闲聊兜底
- `generate_response`：统一组织输出

工具层：`portfolio_tools`（组合汇总）、`market_tools`（报价与历史数据）。状态用 `AgentState` 承载，图构建后以单例方式复用。

风险预警独立于对话：止盈止损线、价格提醒、异常波动告警，触发后主动通知。

## 可复用点

- **意图路由 + 工具节点的最小 Agent 结构**：比多 Agent 协作更轻，适合业务边界清晰的产品
- **风控预警规则**：阈值 + 触发 + 通知，可迁移到资金监控、成本预警
- **行情工具封装**：多数据源聚合的统一接口
- **对话即入口**：一个输入框覆盖查询、分析、问答三类需求

## 实现难度

**中高**。40 页，代码量适中。难点在行情数据源接入与合规边界（投顾建议涉及资质）。
