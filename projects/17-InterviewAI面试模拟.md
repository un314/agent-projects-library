# 17 InterviewAI 面试模拟 Agent

> 多轮对话式模拟面试：按简历与岗位出题，支持技术 / 行为 / 压力三种模式，结束后给出结构化评估。

## 项目定位

一个不知疲倦的面试陪练。它会追问、会施压、会记录，最后给出一份可复盘的反馈报告。

## 要解决的问题

- 面试练习缺少真实对话压力，看题不等于会答
- 练习后没有专业反馈，不知道自己差在哪
- 行为面试的结构化表达（如 STAR）需要反复打磨
- 题库零散，无法按岗位精准匹配

## 核心流程与架构

1. **准备阶段**：上传简历、选择岗位与面试模式（技术 / 行为 / 压力）
2. **出题**：RAG 从题库召回匹配岗位的问题，结合简历经历定制
3. **多轮对话**：AI 面试官根据回答继续追问，压力模式会加快节奏、质疑细节
4. **实时记录**：每轮问答入库，保留时间线
5. **评估反馈**：按维度打分（专业深度、表达结构、逻辑、应变），指出具体问题并给出改进示例
6. **报告**：生成面试总结，可回看完整对话

可选语音输入与语音回复，降低练习时的打字负担。

## 可复用点

- **多轮追问 + 评分 rubric**：对话式评估的通用框架，可迁移到客服质检、销售演练、培训考核
- **题库 + RAG 召回**：按岗位/行业精准出题
- **面试记录模型**：会话、轮次、评分维度、评语
- **三种面试模式的参数化**：用配置控制节奏与追问强度，而不是写三套逻辑

## 实现难度

**中低**。22 页，是 18 份文档中最轻的一份，逻辑集中在对话与评分 Prompt 上，工程复杂度低。
